# 🛡️ Cybersecurity Hands-On Labs

A continuously growing portfolio of hands-on cybersecurity labs covering
offensive security, defensive security, SOC operations, web and API security,
Active Directory, detection engineering, cloud security, and penetration
testing.

This repository documents my practical cybersecurity learning journey through
labs, experiments, vulnerability assessments, evidence, remediation, and
security analysis.

---

## 👨‍💻 About This Repository

This repository contains my hands-on cybersecurity work rather than only
course certificates.

Each lab focuses on a specific security concept and follows a practical
workflow:

> Learn → Build → Attack → Analyze → Detect → Remediate → Document

All security testing is performed in intentionally vulnerable,
self-controlled lab environments.
